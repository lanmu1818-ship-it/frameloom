## 提取范围

从工作台和画布两个入口递归解析静态导入、动态导入及类型导入，共识别 196 个源文件/资源依赖。保留可达前端、共享类型和全局样式；原图片资源采用占位图替代。仅用于 SaaS 管理后台、官网、演示站或其他未被 App 入口使用的文件未进入此次发布。

未复制后端、数据库模型/迁移、原仓库历史、真实环境文件、运行配置文件、用户数据、日志、缓存、构建产物、安装包、发布脚本、浏览器配置文件或 Electron/Tauri 主进程代码。独立安装产生的 node_modules 和 dist 在本地存在，但已被 Git 忽略，源码压缩包也不包含它们。

## 主要改动

- 将原跨目录导入改为独立仓库内路径，显式声明依赖并生成专用锁文件。
- 保留 React 前端路由适配层，去除 Next.js 服务端和 next-auth 包依赖；会话类型改为公开数据契约。
- 去除生产后端锁定和固定客户端凭证，改为首次启动配置或公开环境变量。
- 内部域名、业务素材服务地址和内部教程链接替换为示例配置或本地帮助页。
- 演示照片、效果缩略图、音视频样例和品牌图案不随源码分发；改用自绘 SVG 或空音视频 URL，字体使用系统回退。
- 修复独立构建暴露的 immer 显式依赖缺失与 KaTeX 样式/字体加载问题。
- 将 PostCSS 更新至 8.5.23，统一 AI SDK 5.x 为 5.0.117、provider-utils 3.x 为 3.0.28，修复此次审计发现的依赖问题。
- 增加 README、配置示例、115 条 API 路径模式索引、部署/贡献/安全说明、Apache-2.0 LICENSE 和 NOTICE。
- 增加 GitHub CI、Dependabot、Issue/PR 模板及源代码发布检查。
